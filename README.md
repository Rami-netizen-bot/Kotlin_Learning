# Kotlin Coding Conventions: Homework

## What is a code convention?
Conventions are a set of guidelines that developers follow to make their code more readable and maintainable.

## Naming Conventions

### 1. Camel Case (camelCase)
* **What is it?** The first word starts with a lowercase letter, and each subsequent word starts with an uppercase letter.
* **When to use in Kotlin:** When writing a variable name or function. Be descriptive and use meaningful words.

### 2. Pascal Case (PascalCase)
* **What is it?** A naming convention where the first letter of every word is capitalized, and there are no spaces or punctuation marks between the words.
* **When to use in Kotlin:** For naming classes, files, and interfaces.

### 3. Upper Snake Case (UPPER_SNAKE_CASE)
* **What is it?** A naming convention where words are written in all capital letters and separated by underscores.
* **When to use in Kotlin:** For values that stay the same and never change while the program runs (constants).

## Technical Concepts

### Compile-Time Variable
It is a read-only value that is fully resolved and hardcoded into the bytecode during compilation rather than being calculated when the application runs.
