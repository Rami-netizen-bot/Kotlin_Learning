Coding Convention
Research coding Convention in Kotlin :
What is code convention?
conventions are a set of guidelines that developers follow to make their code more readable and maintainable 
What is camel case?
the first word starts with a lowercase letter, and each subsequent word starts with an uppercase letter. 
When we use camel case in kotlin?
When writing a variable name, be descriptive and use meaningful words. 
What is pascal case ? When we use it in Kotlin?
is a naming convention where the first letter of every word is capitalized, and there are no spaces or punctuation marks between the words. 
What is upper snake case?
Upper snake case is a naming convention where words are written in all capital letters and separated by underscores 
When we use it?
For values that stay the same and never change while the program runs. 
What is compile time variable in Kotlin?
It is a read-only value that is fully resolved and hardcoded into the bytecode during compilation rather than being calculated when the application runs
